# Native explicit exit observation slice

Base 67e674d. Own build/NativeCli and exit-related native adapter changes only. Command: ProxyPartner.Cli exit-ip --profile <existing file> [--age-identity <existing identity>] --node <selected name> [--rounds 1-6] [--node-timeout-ms 1-6000] [--exit-state <caller-owned JSON file>]. Never runs during inspect/probe/current-path. No host mutation or subscription download.

Cost: two cold independent native connections per selected node per round, fixed HTTPS sources ipv4.icanhazip.com and api.ipify.org, sequential to avoid two extra worker threads. Per-source deadline default6000ms, total bound about12000ms plus existing entry DNS/profile initialization. First five-site scoring does not call these endpoints. Body cap64 bytes (65th rejects), headers32KiB, no content decoding, bounded chunk framing. Shared OpenSSL4 stays unchanged. Measure actual package process separately; these are bounds/design costs, not measured memory claims.

New additive C exports (existing exports unchanged): ProbeAnyTlsEcho uses same ProbeAnyTlsWebsite arguments then char* body,unsigned capacity,unsigned* used; ProbeMieruEchoV2 uses same ProbeMieruWebsiteV2 arguments then char* body,unsigned capacity,unsigned* used. ProbeEcho uses the same Shadowsocks ProbeWebsite arguments then char* body,unsigned capacity,unsigned* used. Headers must be empty for these fixed echo requests. Caller provides65-byte buffer. Success means complete HTTP200 body <=64 bytes, not necessarily a public IP. Public-address parsing and normalized family are owned by CLI. Cancellation and remaining deadline are preserved.

JSONL events:
exit_begin {node,protocol,rounds,sources:2,perSourceTimeoutMs,independent:true}
exit_source {node,round,source,host,observedUtc,httpStatus:null|number,elapsedMs:null|number,timedOut,address:null|string,family:null|4|6,state:public|invalid_address|http_error|response_incomplete_or_rejected|transport_failed}
exit_observation {node,round,family,address,observedUtc,observers:1|2,corroboratingAddress:null|string,agreement:single_source|confirmed|conflict,changes,lastVerifiedAddress:null|string,consistentSince:null|string,confirmedSamples}
exit_summary {node,rounds,publicObservations,confirmedFamilies,confirmedObservations,cancelled}
Unknown is null. No credentials, raw body, DNS answers or destination IP are emitted as exit. Return0 if at least one public observation,1 none,2 invalid invocation. Without --exit-state histories begin empty and are session-local. Optional --exit-state imports up to8192 bytes of typed prior facts matching exact selected node, protocol and SHA256 of the original profile bytes. Changed/re-encrypted profile invalidates imported state conservatively. No key, credential or profile body is in state. --rounds is immediate deliberate retest, not a new background schedule. Caller owns persistence/five-minute scheduling.

Compatibility: copy old ParseExitAddress public-range exclusions including mapped IPv4 normalization. Two same-family equal values confirm; same-family unequal values conflict; different families each remain single-source. Retain last verified address/change count and <=1hour consecutive confirmed samples as old UpdateExitObservation. No promise of IPv6 discovery from an IPv4-only endpoint.

Stable frontend state protocol (v1): exit_state_input {state:accepted|ignored,reason:null|invalid_or_different_profile_node} appears only when a state file was provided. Before final exit_summary, emit exactly one exit_state {version:1,node,protocol,profileRevision,families:[{family:4|6,address,lastVerifiedAddress:null|string,changes,confirmedSamples,observedUnixMs,consistentSinceUnixMs}]}. Frontend may persist this entire event unchanged as UTF8 JSON and supply its filename on the next explicit exit-ip call. File is read only by CLI, never overwritten. Invalid input is reported ignored; no partial state imported. A failed new transport preserves valid prior facts; absence of fresh observations is not an outage or fresh confirmation. confirmedFamilies counts distinct families with latest fresh agreement this command, while confirmedObservations counts all confirmed pair events across rounds. Never treat historical confirmedSamples as proof of a fresh failed request.

Serialization order: catalog (existing CLI), exit_begin, optional exit_state_input, pairs of exit_source followed by exit_observation(s), exit_state, exit_summary. Existing website events and target counts are untouched. All body/IP output goes only to the explicitly requested result/state stream, never credential logs. IPv4/IPv6 observations each carry a family. Sample payloads in handoff use placeholders rather than real addresses.
