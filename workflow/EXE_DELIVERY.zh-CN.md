# ProxyPartner.exe 交付执行文档

2026-11-09 · 当前基线 `e75cd00`

## 用户打开后要看到什么

日常运行一个现有代理软件，例如 Clash Verge。它可以留在后台。解压 Windows x64 便携包，双击 `ProxyPartner.exe` 打开节点表。软件自动连接本机正在使用的宿主，显示节点、策略组和当前选择。宿主暂时不可读时，窗口显示连接状态和等待原因。

在表里挑候选节点、选要测的网站，查看逐目标的测量、样本数和评分理由。Google、YouTube、ChatGPT 使用网站入口，OpenAI 和 Anthropic 使用已核对的 HTTPS API 入口。测量按节点和目标记录，数据不足显示待测。关窗缩到托盘，从托盘可以重开或退出。

当前交付按项目的只读边界执行。你在 Clash Verge 改选后，ProxyPartner 读取新的选择。将来若加入由 ProxyPartner 发出的手动切换，需要单独确认并更新项目对宿主选点与缓存的边界。其它代理软件是可替换的宿主，按实际接入证据增加支持。 [产品规格](../spec/PRODUCT.md) [项目约束](../AGENTS.md)

## 从现在到便携包的执行顺序

| 阶段 | 任务 | 可核验的交付 |
|---|---|---|
| 构建入口 | T00 | 在 Windows x64 上核对 SDK、C++ 构建工具、SQLite、Go、宿主版本与许可证。用真实构建和运行验证发布路径，锁定依赖来源。 |
| 接入和窗体 | T01–T03 | 建立全进程树测量，验证普通用户只读接入。发布首个桌面基线并打开窗口，以相同负载比较 Win32 与最小 Avalonia 候选。 |
| 可用观察版 | T04–T06 | 真正的节点身份、重复历史去重、SQLite 和窗口形成闭环。从便携目录双击 `ProxyPartner.exe`，看到宿主节点和当前项，重启后还能看历史。交付标为 `observer-preview`。 |
| 逐节点测试和评分 | T07–T10 | 评分规则可解释。以获准的真实线路验证单节点测试、取消、网站与 API 记录、出口观察及可比范围。证据不足的线路显示待测或未验证，真实样本才进入排名。 |
| 正式 Lite | T11 | 在干净的 Windows 环境验证解压双击、托盘和退出。完成 24 小时运行、性能与宿主无干扰验收。归档便携 ZIP、发布命令、依赖许可、来源、提交 SHA 和文件哈希。 |

## 正式交付判定

- **开得起来。** Windows x64 普通用户解压便携目录后，双击主程序可启动。开发机承担构建工具依赖。发行包按实测带齐需要的本机组件和按需测量进程。
- **接得到、用得上。** 真实宿主可读，节点与组清楚分开。选中项变化可反映，站点状态、历史、样本量和评分解释可检查。已知失败和未测在界面分别显示。
- **测对线路。** 核对至少两条获准的真实线路，保留可追溯的路径证据。网页响应、API 鉴权、模型业务可用性分开判定。现有五目标终端结果是当前代理路径的开发证据，逐节点排名由真实逐节点样本支持。
- **资源达标。** 按原预算测量托盘 p95 25 MiB、窗口 p95 35 MiB 目标和所有产品进程峰值 40 MiB 门槛。记录空闲 CPU、循环开关窗口及 24 小时运行证据。
- **只读和许可达标。** 用请求及宿主状态证据核对接入白名单和无干扰。自研代码按 MIT，按固定版本核对上游许可和来源。Mihomo、faceair 的 GPL 源码供接口与行为参考。独立测量代码选用经审查的许可兼容实现。 [资源标准](../spec/PERFORMANCE.md) [来源清单](../research/SOURCE_AUDIT.md)

## 交接和产物位置

统筹在独立工作树派给一个实施者。前端负责桌面，后端负责接入、存储与测量，算法负责评分和口径，测试独立复验。候选及集成均按实际 SHA 交命令、退出码、证据文件与 SHA256。失败按已定返工上限处理，缺少必要前提时留下检查点和恢复条件。 [交接规则](HANDOFF.zh-CN.md) [退出与恢复](BREAKOUT.zh-CN.md)

正式发布物计划归档在本机 `runs/release/<已验收SHA>/`，包括可双击的 `ProxyPartner.exe` 所在目录、便携 ZIP、使用说明和验收回执。发布目录以实际构建产物为准。
